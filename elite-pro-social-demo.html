Stack técnico del proyecto completo

Esta ventana es una demo autocontenida (sin servidor) para mostrar el diseño y flujo de Elite-Pro Social. La aplicación completa incluye backend real en Node.js/Express con base de datos SQLite, autenticación JWT, mensajería en tiempo real con Socket.io y panel de administración conectado a datos reales.
